# skills/ 目录说明（本文件不注入 AI）

这里是 **AI 技能文档库**（训练科学标准口径整理）：App 生成 AI 报告（复盘/规划/
减量/对比）与直接对话时，会把本目录下的技能 Markdown 全文注入提示词的
「专业知识库」段，保证切换任意 AI 模型都能拿到一致的领域知识与撰写规范。

## 与运行时扫描的差异（App 版）

旧 Web 版每次 AI 请求实时扫描本目录；App 无法在运行时读仓库目录，改为
**构建期内嵌**：`scripts/embed-skills.mjs` 把本目录全部技能生成
`src/prompts/skills.ts`（产物入库）。因此**改了这里的 .md 必须重跑内嵌脚本**：

```bash
node scripts/embed-skills.mjs
```

## 添加新技能

把 `.md` 文件放进本目录后重跑上面的脚本即可：

- 文件名即排序依据，用 `NN-名称.md` 数字前缀控制注入顺序；
- 文件首行的一级标题（`# 标题`）会作为该技能在提示词中的小节标题，缺失则用文件名；
- 空文件自动跳过；
- 内容用中文撰写，聚焦「AI 解读数据时需要遵守的口径、阈值与标准」，避免重复
  提示词「指标口径与骑手参数」段已有的动态数值（那里反映骑手当前实际参数，优先级更高）；
- 英文版技能用 `.en.md` 后缀，与中文版同名配对（如 `01-coggan-power.md` / `01-coggan-power.en.md`）。

## 规则

- `_` 开头的文件（如本文件）**不会**被注入，用于存放说明文档；
- 只识别 `.md` 扩展名；
- 内嵌口径：按文件名排序、`_` 前缀跳过、`.en.md` 归英文、其余归中文
  （见 `src/prompts/skills.ts` 中的 `buildSkillsSection`）。
